PowerBar 0.8

  • The Dashboard widget shows every new song's cover. From the third song on, it could show an earlier song's cover instead, which was easiest to see with PowerBar's window closed.
  • PowerBar updates the installed widget when 0.8 starts. If the widget is open in Dashboard at that moment, remove it and add it again (or log out and back in) to load the new version.
  • Opening a feature (such as Why This Song) right after cancelling another one no longer sometimes picks up the cancelled feature's question.
