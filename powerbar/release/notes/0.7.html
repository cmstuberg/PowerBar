PowerBar 0.7

  • PowerBar now updates itself. PowerBar › Check for Updates… looks for a new version, and PowerBar checks once a day by itself if you let it (it asks the second time you open it).
  • Updates come over modern, verified HTTPS and are signed: PowerBar checks each update's signature before installing it, and refuses anything that doesn't match.
  • After an update, an installed Dashboard widget is refreshed to the new version automatically.

Coming from 0.6? Install 0.7 by hand this once (0.6 can't update itself). From 0.7 on, new versions arrive by themselves.
